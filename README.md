# Portfolio

A personal portfolio built with [Astro](https://astro.build) and deployed on Netlify.

## Run it locally

```bash
npm install
npm run dev
```

The site runs at http://localhost:4321.

## Edit the content

All text, projects and links are in `src/data/site.ts`.

## Deploy

Netlify builds the site from `netlify.toml` each time you push to GitHub.
